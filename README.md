# neto-homepage-preview
Static visual homepage concept for Neto Designs review only; no checkout or live store changes

## Image sources

- Original logo retained from this preview.
- The hoodie, crewneck and full-zip sweatshirt photographs come from the corresponding public Neto Designs product pages.
- The plain T-shirt and chef jacket come from the existing Neto Designs preview asset library. The casacca (ND001456), camice (ND001674) and apron (ND001925) are archived Neto catalogue images. Those references identify the photos and do not verify inventory.
- Workshop and LAB interiors come from the existing Neto Designs photo library.
- Published work and LAB transformations use verified photographs.
